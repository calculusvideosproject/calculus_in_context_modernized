Exercise 18.

There and back again. In the text we went one day into the future and then back again to the present. Here you’ll go forward two days from \(t = 0\) and then back again. There are two ways to do this: with a time step of \(\Delta t = \pm 2\) (as in the previous question), and with a pair of time steps of \(\Delta t = \pm 1\) .
🔗

(a)

(\(\Delta t = \pm 2\)). Using the values of \(S\text{,}\) \(I\text{,}\) and \(R\) at time \(t = 2\) that you just got in the previous question, calculate the rates \(S'\text{,}\) \(I'\text{,}\) and \(R'\text{.}\) Then using a time step of \(\Delta t = -2\text{,}\) estimate new values of \(S\text{,}\) \(I\text{,}\) and \(R\) at time \(t = 0\text{.}\) How much do these new values differ from the original values 45,400, 2100, 2500?
🔗
🔗

(b)

(\(\Delta t = \pm 1\)). Now make a new start, using the values
\begin{align*} S \amp= 43156.1, \amp I \amp= 3986.5, \amp R \amp= 2857.4,\\ S' \amp= -1720.4, \amp I' \amp= 1435.7, \amp R' \amp= 284.7. \end{align*}
that occur when \(t = 2\) if we make estimates with a time step \(\Delta t = 1\text{.}\) (These values come from Table 1.1.9) Using two rounds of calculations with a time step of \(\Delta t = -1\text{,}\) estimate another set of new values for \(S\text{,}\) \(I\text{,}\) and \(R\) at time \(t = 0\text{.}\) How much do these new values differ from the original values 45,400, 2100, 2500?
🔗
🔗

(c)

Which process leads to a smaller set of differences: a single round of calculations with \(\Delta t = \pm 2\text{,}\) or two rounds of calculations with \(\Delta t = \pm 1\text{?}\) Consequently, which process produces better estimates—in the sense in which we used to measure estimates in Subsubsection 1.1.6.5?
