    Section 10.2 Taylor Polynomials

    The general setting..

    In chapter 3 we discovered that functions were locally linear at most points—when we zoomed in on them they looked more and more like straight lines. This fact was central to the development of much of the subsequent material. It turns out that this is only the initial manifestation of an even deeper phenomenon: Not only are functions locally linear, but, if we don’t zoom in quite so far, they look locally like parabolas. From a little further back still they look locally like cubic polynomials, etc. Later in this section we will see how to use the computer to visualize these “local parabolizations”, “local cubicizations”, etc. Let’s summarize the idea and then explore its significance:
    🔗
    CommentsThe “at most points” qualification is because of exceptions like those we ran into when we explored locally linearity. The function \(|x|\text{,}\) for instance, was not locally linear at \(x=0\)—it’s not locally like any polynomial of higher degree at that point either. The issue of what “goodness of fit” means and how it is measured is a subtle one which we will develop over the course of this section. For the time being, your intuition is a reasonable guide—one fit to a curve is better than another near some point if it “shares more phosphor” with the curve when they are graphed on a computer screen centered at the given point.
    🔗
    The fact that functions look locally like polynomials has profound implications conceptually and

    Aside
    The behavior of a function can often be inferred from the behavior of a local polynomialization
    🔗
    computationally. It means we can often determine the behavior of a function locally by examining the corresponding behavior of what we might call a “local polynomialization” instead. In particular, to find the values of a function near some point, or graph a function near some point, we can deal with the values or graph of a local polynomialization instead. Since we can actually evaluate polynomials directly, this can be a major simplification.
    🔗
    There is an extra feature to all this which makes the concept particularly attractive: not only are functions locally polynomial,

    Aside
    We want the best fit at \(x=0\)
    🔗
    it is easy to find the coefficients of the polynomials. Let’s see how this works. Suppose we had some function \(f(x)\) and we wanted to find the fifth degree polynomial that best fit this function at \(x=0\text{.}\) Let’s call this polynomial
    \begin{equation*} P(x) = a_0+a_1x+a_2x^2+a_3x^3+a_4x^4+a_5x^5. \end{equation*}
    To determine \(P\text{,}\) we need to find values for the six coefficients \(a_0\text{,}\) \(a_1\text{,}\) \(a_2\text{,}\) \(a_3\text{,}\) \(a_4\text{,}\) \(a_5\text{.}\)
    🔗
    Before we can do this, we need to define what we mean by the “best” fit to \(f\) at \(x=0\text{.}\) Since we have six unknowns, we need six conditions. One obvious

    Aside
    The best fit should pass through the point \((0, f(0))\)
    🔗
    condition is that the graph of \(P\) should pass through the point \((0, f(0))\text{.}\) But this is equivalent to requiring that \(P(0)=f(0)\text{.}\) Since \(P(0)=a_0\text{,}\) we thus must have \(a_0=f(0)\text{,}\) and we have found one of the coefficients of \(P(x)\text{.}\) Let’s summarize the argument so far:
    🔗
    But we’re

    Aside
    The best fit should have the right slope at \((0, f(0))\)
    🔗
    not interested in just any polynomial passing through the right point; it should be headed in the right direction as well. That is, we want the slope of \(P\) at \(x=0\) to be the same as the slope of \(f\) at this point—we want \(P'(0)=f'(0).\) But
    \begin{equation*} P'(x) = a_1 + 2a_2x + 3a_3x^2 + 4a_4x^3 + 5a_5x^4, \end{equation*}
    so \(P'(0)=a_1\text{.}\) Our second condition therefore must be that \(a_1=f'(0)\text{.}\) Again, we can summarize this as
    🔗
    Note that at this point we have recovered the general form for the local linear approximation to \(f\) at \(x=0\text{:}\) \(L(x) = f(0) + f'(0)x\text{.}\)
    🔗
    But there is no reason to stop with the first derivative. Similarly, we would want the way in which the slope of \(P(x)\) is changing—we are now talking about \(P''(0)\)—to behave the way the slope of \(f\) is changing at \(x=0\text{,}\) etc. Each higher derivative controls a more subtle feature of the shape of the graph. We now see how we could formulate reasonable additional conditions which would determine the remaining coefficients of \(P(x)\text{:}\)
    🔗
    Since \(P(x)\) is a fifth degree polynomial, all the derivatives of \(P\) beyond the fifth will be identically 0, so we can’t control their values by altering the values of the \(a_k\text{.}\) What we are saying, then, is that we are using as our

    Aside
    The final criterion for best fit at \(x=0\)
    🔗
    criterion for the best fit that all the derivatives of \(P\) as high as we can control them have the same values at \(x=0\) as the corresponding derivatives of \(f\text{.}\)
    🔗
    While this is a reasonable definition for something we might call the “best fit” at the point \(x=0\text{,}\) it gives us no direct way to tell how good the fit really is. This is a serious shortcoming—if we want to approximate function values by polynomial values, for instance, we would like to know how many decimal places in the polynomial values are going to be correct. We will take up this question of goodness of fit later in this section; we’ll be able to make measurements that allow us to to see how well the polynomial fits the function. First, though, we need to see how to determine the coefficients of the approximating polynomials and get some practice manipulating them.
    🔗

    Note on Notation:.

    We have used the

    Aside
    Notation for higher derivatives
    🔗
    notation \(f^{(5)}(x)\) to denote the fifth derivative of \(f(x)\) as a convenient shorthand for \(f'''''(x)\text{,}\) which is harder to read. We will use this throughout.
    🔗
    Finding the coefficientsWe first observe that the derivatives of \(P\) at \(x=0\) are easy to express in terms of \(a_1,a_2,\ldots \, .\) We have
    \begin{align*} P'(x) \amp= a_1+2\,a_2x+3\,a_3x^2+4\,a_4x^3+5\,a_5x^4,\\ P''(x)\amp= 2\,a_2+3\cdot2\,a_3x+4\cdot3\,a_4x^2+5\cdot4\,a_5x^3,\\ P^{(3)}(x)\amp= 3\cdot2\,a_3+4\cdot3\cdot2\,a_4x+5\cdot4\cdot3\,a_5x^2,\\ P^{(4)}(x)\amp= 4\cdot3\cdot2\,a_4+5\cdot4\cdot3\cdot2\,a_5x,\\ P^{(5)}(x)\amp= 5\cdot4\cdot3\cdot2\,a_5. \end{align*}
    Thus \(P''(0)=2\,a_2\text{,}\) \(P^{(3)}(0)= 3\cdot2\,a_3\text{,}\) \(P^{(4)}(0)= 4\cdot3\cdot2\,a_4\text{,}\) and \(P^{(5)}(0)=5\cdot4\cdot3\cdot2\,a_5 \, .\)
    🔗
    We can simplify this a bit by introducing the factorial notation, in which we write \(n!=n\cdot(n-1)\cdot(n-2)\cdots3\cdot2\cdot1 \, .\) This is called “\(n\) factorial".

    Aside
    Factorial notation
    🔗
    Thus, for example, \(7!=7\cdot6\cdot5\cdot4\cdot3\cdot2\cdot1 = 5040.\) It turns out to be convenient to extend the factorial notation to 0 by defining \(0!=1.\) (Notice, for instance, that this makes the formulas below work out right.) In the exercises you will see why this extension of the notation is not only convenient, but reasonable as well!
    🔗
    With this notation

    Aside
    The desired rule for finding the coefficients
    🔗
    we can express compactly the equations above as \(P^{(k)}(0)=k!\,a_k\) for \(k=0\text{,}\) 1, 2, …5  . Finally, since we want \(P^{(k)}(0)=f^{(k)}(0)\text{,}\) we can solve for the coefficients of \(P(x)\text{:}\)
    \begin{equation*} a_k = \frac{f^{(k)}(0)}{k!} \quad \text{for $k=0,1,2,3,4,5$}. \end{equation*}
    🔗
    We can now write down an explicit formula for the fifth degree polynomial which best fits \(f(x)\) at \(x=0\) in the sense we’ve put forth:
    \begin{equation*} P(x) = f(0) + f'(0)x + \frac{f^{(2)}(0)}{2!}x^2 + \frac{f^{(3)}(0)}{3!}x^3 + \frac{f^{(4)}(0)}{4!}x^4 + \frac{f^{(5)}(0)}{5!}x^5. \end{equation*}
    We can express this more compactly using the \(\Sigma\)–notation we introduced in the discussion of Riemann sums in chapter 6:
    \begin{equation*} P(x)=\sum_{k=0}^{5} \frac{f^{(k)}(0)}{k!}\,x^k. \end{equation*}
    We call this the fifth degree Taylor polynomial for \(f(x)\). It is sometimes also called the fifth order Taylor polynomial.
    🔗
    It should be obvious to you that we can generalize what we’ve done above to get a

    Aside
    General rule for the Taylor polynomial at \(x=0\)
    🔗
    best-fitting polynomial of any degree. Thus
    🔗
    We also speak of the Taylor polynomial centered at \(x=0\text{.}\)
    🔗
    Example. Consider \(f(x) = \sin(x)\text{.}\) Then for \(n=7\) we have
    \begin{align*} f(x) \amp= \sin(x), \amp\qquad f(0) \amp= 0,\\ f'(x) \amp= \cos(x), \amp f'(0) \amp= +1,\\ f^{(2)}(x) \amp= -\sin(x), \amp f^{(2)}(0) \amp= 0,\\ f^{(3)}(x) \amp= -\cos(x), \amp f^{(3)}(0) \amp= -1,\\ f^{(4)}(x) \amp= \sin(x), \amp f^{(4)}(0) \amp= 0,\\ f^{(5)}(x) \amp= \cos(x), \amp f^{(5)}(0) \amp= +1,\\ f^{(6)}(x) \amp= -\sin(x), \amp f^{(6)}(0) \amp= 0,\\ f^{(7)}(x) \amp= -\cos(x), \amp f^{(7)}(0) \amp= -1. \end{align*}
    From this we can see that the pattern 0, \(+1\text{,}\) 0 , \(-1\text{,}\) …will repeat forever. Substituting these values into the formula we get that for any odd integer \(n\) the \(n\)-th degree Taylor polynomial for \(\sin(x)\) is
    \begin{equation*} P_n(x) = x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dfrac{x^7}{7!} + \cdots \pm {x^n}{n!}. \end{equation*}
    🔗
    Note that \(P_3(x)=x-x^3/6\text{,}\) which is the polynomial we met in section 1. We saw there that this polynomial seemed to fit the graph of the sine function only out to around \(x=1\text{.}\) Now, though, we have a way to generate polynomial approximations of higher degrees, and we would expect to get better fits as the degree of the approximating polynomial is increased. To see how closely these polynomial approximations follow \(\sin(x)\text{,}\) here’s the graph of \(\sin(x)\) together with the Taylor polynomials of degrees \(n=1,3,5,\ldots ,17\) plotted over the interval \([0, 7.5]\text{:}\)
    🔗
    While each polynomial eventually wanders off

    Aside
    The higher the degree of the polynomial, the better the fit
    🔗
    to infinity, successive polynomials stay close to the sine function for longer and longer intervals—the Taylor polynomial of degree 17 is just beginning to diverge visibly by the time \(x\) reaches \(2\pi\text{.}\) We might expect that if we kept going, we could find Taylor polynomials that were good fits out to \(x=100\text{,}\) or \(x=1000\text{.}\) This is indeed the case, although they would be long and cumbersome polynomials to work with. Fortunately, as you will see in the exercises, with a little cleverness we can use a Taylor polynomial of degree 9 to calculate \(\sin(100)\) to 5 decimal place accuracy.
    🔗
    Other Taylor Polynomials:

    Aside
    Approximating polynomials for other basic functions
    🔗
    In a similar fashion, we can get Taylor polynomials for other functions. You should use the general formula to verify the Taylor polynomials for the following basic functions. (The Taylor polynomial for \(\sin(x)\) is included for convenient reference.)

    Subsection 10.2.1 New Taylor Polynomials from Old

    Given a function we want to approximate by Taylor polynomials, we could always go straight to the general formula for deriving such polynomials. On the other hand, it is often possible to avoid a lot of tedious calculation of derivatives by using a polynomial we’ve already calculated. It turns out that any manipulation on Taylor polynomials you might be tempted to try will probably work. Here are some examples to illustrate the kinds of manipulations that can be performed on Taylor polynomials.
    🔗

    Substitution in Taylor Polynomials..

    Suppose we wanted the Taylor polynomial for \(e^{x^2}\text{.}\) We know from what we’ve already done that for any value of \(u\) close to 0,
    \begin{equation*} e^u \approx 1 + u + \dfrac{u^2}{2!} + \dfrac{u^3}{3!} + \dfrac{u^4}{4!} + \cdots + \dfrac{u^n}{n!}. \end{equation*}
    In this expression \(u\) can be anything, including another variable expression. For instance, if we set \(u=x^2\text{,}\) we get the Taylor polynomial
    \begin{align*} e^{x^2} \amp= e^u\\ [-3pt] \amp\approx 1 + u + \dfrac{u^2}{2!} + \dfrac{u^3}{3!} + \dfrac{u^4}{4!} + \cdots + \dfrac{u^n}{n!}\\ [3pt] \amp= 1 + (x^2) + \dfrac{(x^2)^2}{2!} + \dfrac{(x^2)^3}{3!} + \dfrac{(x^2)^4}{4!} + \cdots + \dfrac{(x^2)^n}{n!}\\ [3pt] \amp= 1 + x^2 + \dfrac{x^4}{2!} + \dfrac{x^6}{3!} + \dfrac{x^8}{4!} + \cdots + \dfrac{x^{2n}}{n!}. \end{align*}
    You should check to see that this is what you get if you apply the general formula for computing Taylor polynomials to the function \(e^{x^2}\text{.}\)
    🔗
    Similarly, suppose we wanted a Taylor polynomial for \(1/(1+x^2)\text{.}\) We could start with the approximation given earlier:
    \begin{equation*} \dfrac{1}{1-u} \approx 1+u+u^2+u^3+\cdots +u^n. \end{equation*}
    If we now replace \(u\) everywhere by \(-x^2\text{,}\) we get the desired expansion:
    \begin{align*} dfrac {1}{1+x^2} = \dfrac{1}{1-(-x^2)} \amp= \dfrac{1}{1-u}\\ \amp\approx 1+u+u^2+u^3+\cdots +u^n\\ [3pt] \amp= 1+(-x^2)+(-x^2)^2+(-x^2)^3+\cdots +(-x^2)^n\\ [3pt] \amp= 1-x^2+x^4-x^6+\cdots \pm x^{2n}. \end{align*}
    Again, you should verify that if you start with \(f(x)=1/(1+x^2)\) and apply to \(f\) the general formula for deriving Taylor polynomials, you will get the preceding result. Which method is quicker?
    🔗
    🔗

    Multiplying Taylor Polynomials..

    Suppose we wanted the 5-th degree Taylor polynomial for \(e^{3x}\cdot \sin(2x)\text{.}\) We can use substitution to write down polynomial approximations for \(e^{3x}\) and \(\sin(2x)\text{,}\) so we can get an approximation for their product by multiplying the two polynomials:
    \begin{align*} lefteqn{e^{3x} \cdot \sin(2x)}\quad\\ \amp\approx \left(1 + (3x)+ \dfrac{(3x)^2}{2!} + \dfrac{(3x)^3}{3!} + \dfrac{(3x)^4}{4!} + \dfrac{(3x)^5}{5!}\right) \left((2x) - \dfrac{(2x)^3}{3!} + \dfrac{(2x)^5}{5!}\right)\\ \amp\approx 2x + 6x^2 + \dfrac{23}{3}x^3 + 5x^4 - \dfrac{61}{60}x^5. \end{align*}
    Again, you should try calculating this polynomial directly from the general rule, both to see that you get the same result, and to appreciate how much more tedious the general formula is to use in this case.
    🔗
    In the same way, we can also divide Taylor polynomials, raise them to powers, and chain them by composition. The exercises provide examples of some of these operations.
    🔗
    🔗

    Differentiating Taylor Polynomials..

    Suppose we know a Taylor polynomial for some function \(f\text{.}\) If \(g\) is the derivative of \(f\text{,}\) we can immediately get a Taylor polynomial for \(g\) (of degree one less) by differentiating the polynomial we know for \(f\text{.}\) You should review the definition of Taylor polynomial to see why this is so. For instance, suppose \(f(x) = 1/(1-x)\) and \(g(x) =1/(1-x)^2\text{.}\) Verify that \(f'(x) = g(x)\text{.}\) It then follows that
    \begin{align*} dfrac{1}{(1-x)^2} = \dfrac{d}{dx} \left(\dfrac{1}{1 - x}\right) \amp\approx \dfrac{d}{dx} (1 + x + x^2 + \cdots + x^n)\\ [3pt] \amp= 1 + 2x + 3x^2 + \cdots + nx^{n-1}. \end{align*}
    🔗
    🔗

    Integrating Taylor Polynomials..

    Again suppose we have functions \(f(x)\) and \(g(x)\) with \(f'(x) = g(x)\text{,}\) and suppose this time that we know a Taylor polynomial for \(g\text{.}\) We can then get a Taylor polynomial for \(f\) by antidifferentiating term by term. For instance, we find in chapter 11 that the derivative of \(\arctan(x)\) is \(1/(1+x^2)\text{,}\) and we have seen above how to get a Taylor polynomial for \(1/(1+x^2)\text{.}\) Therefore we have
    \begin{align*} arctan{x} = \int_0^x \frac{1}{1+t^2} dt \amp\approx \int_0^x \left( 1-t^2+t^4-t^6+ \cdots \pm t^{2n}\right) dt\\ [3pt] \amp= \left. t-\dfrac{1}{3}t^3 + \dfrac{1}{5} t^5 - \cdots \pm \dfrac{1}{2n+1}t^{2n+1} \; \right|_0^x\\ [3pt] \amp= x - \dfrac{1}{3}x^3 + \dfrac{1}{5} x^5 - \cdots \pm \dfrac{1}{2n+1}x^{2n+1}. \end{align*}

    Subsection 10.2.3 Taylor’s theorem

    Taylor’s theorem

    Aside
    Order of magnitude
    🔗
    is the generalization of what we have just seen; it describes the goodness of fit between an arbitrary function and one of its Taylor polynomials. We’ll state three versions of the theorem, gradually uncovering more information. To get started, we need a way to compare the order of magnitude of any two functions.
    🔗
    Now, when \(\lim_{x\to a} \varphi(x)/q(x)\) is \(C\text{,}\) we have
    \begin{equation*} \varphi(x) \approx C q(x) \quad \mbox{when $x \approx a$}. \end{equation*}
    We’ll frequently use this relation to express the idea that \(\varphi(x)\) has the same order of magnitude as \(q(x)\) as \(x \to a\text{.}\)
    🔗
    The symbol \(O\) is an upper case “oh”.

    Aside
    ‘Big oh’ notation
    🔗
    When \(\varphi(x) = O(q(x))\) as \(x \to a\text{,}\) we say \(\varphi(x)\) is ‘big oh’ of \(q(x)\) as \(x\) approaches \(a\). Notice that the equal sign in \(\varphi(x) = O(q(x))\) does not mean that \(\varphi(x)\) and \(O(q(x))\) are equal; \(O(q(x))\) isn’t even a function. Instead, the equal sign and the \(O\) together tell us that \(\varphi(x)\) stands in a certain relation to \(q(x)\text{.}\)
    🔗
    This version of Taylor’s theorem focusses

    Aside
    Informal language
    🔗
    on the general shape of the remainder function. Sometimes we just say the remainder has “order \(n + 1\)”, using this short phrase as an abbreviation for “the order of magnitude of the function \((x - a)^{n+1}\)”. In the same way, we say that a function and its \(n\)-th degree Taylor polynomial at \(x = a\) agree to order \(n+1\) as \(x \to a\).
    🔗

    Aside
    Notice that, if \(\varphi(x) = O(x^3)\) as \(x \to 0\text{,}\) then it is also true that \(\varphi(x) = O(x^2)\) (as \(x \to 0\)). This implies that we should take \(\varphi(x) = O(x^n)\) to mean “\(\varphi\) has at least order \(n\)” (instead of simply “\(\varphi\) has order \(n\)”). In the same way, it would be more accurate (but somewhat more cumbersome) to say that \(\varphi = O(q)\) means “\(\varphi\) has at least the order of magnitude of \(q\)”.
    🔗
    As we saw in our example, we can translate the order

    Aside
    Decimal places of accuracy
    🔗
    of agreement between the function and the polynomial into information about the number of decimal places of accuracy in the polynomial approximation. In particular, if \(x - a = 0\) to \(k\) decimal places, then \((x - a)^n = 0\) to \(nk\) places, at least. Thus, as the order of magnitude \(n\) of the remainder increases, the fit increases, too. (You have already seen this illustrated with the sine function and its various Taylor polynomials, in the figure on page .)
    🔗
    While the first version of Taylor’s theorem tells us that \(R(x)\)

    Aside
    A formula for the remainder
    🔗
    looks like \((x - a)^{n+1}\) in some general way, the next gives us a concrete formula. At least, it looks concrete. Notice, however, that \(R(x)\) is expressed in terms of a number \(c_x\) (which depends upon \(x\)), but the formula doesn’t tell us how \(c_x\) depends upon \(x\text{.}\) Therefore, if you want to use the formula to compute the value of \(R(x)\text{,}\) you can’t. The theorem says only that \(c_x\) exists; it doesn’t say how to find its value. Nevertheless, this version provides useful information, as you will see.
    🔗
    We can use the Lagrange form

    Aside
    Another formula for the remainder
    🔗
    as an aid to computation. To see how, return to the formula
    \begin{equation*} R(x) \approx C (x - a)^{n+1} \quad (x \approx a) \end{equation*}
    that expresses \(R(x) = O((x - a)^{n+1})\) as \(x \to a\) (see page ). The constant here is the limit
    \begin{equation*} C = \lim_{x \to a} \dfrac{R(x)}{(x - a)^{n+1}}. \end{equation*}
    If we have a good estimate for the value of \(C\text{,}\) then \(R(x) \approx C (x - a)^{n+1}\) gives us a good way to estimate \(R(x)\text{.}\) Of course, we could just evaluate the limit to determine \(C\text{.}\) In fact, that’s what we did in the example; knowing \(C \approx .008\) there gave us two more decimal places of accuracy in our polynomial approxmation to the sine function.
    🔗
    But the Lagrange form of the remainder

    Aside
    Determining \(C\) from \(f\) at \(x = a\)
    🔗
    gives us another way to determine \(C\text{:}\)
    \begin{align*} C = \lim_{x \to a} \dfrac{R(x)}{(x - a)^{n+1}} \amp= \lim_{x \to a} \dfrac{f^{(n+1)}(c_x)}{(n+1)!}\\ [3pt] \amp= \dfrac{f^{(n+1)}(\lim_{x \to a} c_x)}{(n+1)!}\\ [3pt] \amp= \dfrac{f^{(n+1)}(a)}{(n+1)!}. \end{align*}
    In this argument, we are permitted to take the limit “inside” \(f^{(n+1)}\) because \(f^{(n+1)}\) is a continuous function. (That is one of the hypotheses of version 2.) Finally, since \(c_x\) lies between \(x\) and \(a\text{,}\) it follows that \(c_x \to a\) as \(x \to a\text{;}\) in other words, \(\lim_{x \to a}c_x = a\text{.}\) Consequently, we get \(C\) directly from the function \(f\) itself, and we can therefore write
    \begin{equation*} R(x) \approx \dfrac{f^{(n+1)}(a)}{(n+1)!} \, (x - a)^{n+1} \qquad (x \approx a). \end{equation*}

    The third version of Taylor’s theorem

    🔗
    uses the Lagrange form of the remainder in a similar way to get an error bound for the polynomial approximation based on the size of \(f^{(n+1)}(x)\text{.}\)

    Let’s see what additional light version 3

    \begin{equation*} |f'''(x)| \leq f'''(99.5) = \tfrac{3}{8} \, (99.5)^{-5/2} < 3.8 \times 10^{-6}. \end{equation*}
    Therefore, from version 3 of Taylor’s theorem,
    \begin{equation*} |\sqrt{x} - Q(x)| < \dfrac{3.8 \times 10^{-6}}{3!} \, |x - 100|^3 \end{equation*}
    Since \(|x - 100| < .5\text{,}\) \(|x - 100|^3 < .125\text{,}\) so
    \begin{equation*} |\sqrt{x} - Q(x)| < \dfrac{3.8 \times 10^{-6} \times .125}{6} = .791667 \times 10^{-7} < .5 \times 10^{-6}. \end{equation*}
    This proves \(\sqrt{x} = Q(x)\) to 6 decimal places—confirming what we found earlier.

    Subsection 10.2.4 Applications

    Evaluating Functions..

    An obvious use

    Aside
    Now you can do anything your calculator can!
    🔗
    of Taylor polynomials is to evaluate functions. In fact, whenever you ask a calculator or computer to evaluate a function—trigonometric, exponential, logarithmic—it is typically giving you the value of an appropriate polynomial (though not necessarily a Taylor polynomial).
    🔗
    Evaluating Integrals. The fundamental theorem of calculus gives us a quick way of evaluating a definite integral provided we can find an antiderivative for the function under the integral (cf. chapter 6.4). Unfortunately, many common functions, like \(e^{-x^2}\) or \((\sin{x} )/x\text{,}\) don’t have antiderivatives that can be expressed as finite algebraic combinations of the basic functions. Up until now, whenever we encountered such a function we had to rely on a Riemann sum to estimate the integral. But now we have Taylor polynomials, and it’s easy to find an antiderivative for a polynomial! Thus, if we have an awkward definite integral to evaluate, it is reasonable to expect that we can estimate it by first getting a good polynomial approximation to the integrand, and then integrating this polynomial. As an example, consider the error function, erf\((t)\text{,}\)

    Aside
    The error function
    🔗
    defined by
    \begin{equation*} \mbox{erf$(t)$} = \dfrac{2}{\sqrt{\pi}}\int_0^t e^{-x^2} \, dx\, . \end{equation*}
    This is perhaps the most important integral in statistics. It is the basis of the so-called “normal distribution" and is widely used to decide how good certain statistical estimates are. It is important to have a way of obtaining fast, accurate approximations for erf\((t)\text{.}\) We have already seen that
    \begin{equation*} e^{-x^2} \approx 1 - x^2 + \dfrac{x^4}{2!} - \dfrac{x^6}{3!} + \dfrac{x^8}{4!} - \cdots \pm \dfrac{x^{2n}}{n!}. \end{equation*}
    Now, if we antidifferentiate term by term:
    \begin{align*} int e^{-x^2}\, dx \amp\approx \int \left( 1 - x^2 + \dfrac{x^4}{2!} - \dfrac{x^6}{3!} + \dfrac{x^8}{4!} - \cdots \pm \dfrac{x^{2n}}{n!}\right) \, dx\\ [3pt] \amp= \int 1 \, dx - \int x^2 \, dx + \int \dfrac{x^4}{2!} \, dx - \int \dfrac{x^6}{3!} \, dx + \cdots \pm \int \dfrac{x^{2n}}{n!} \, dx\\ [3pt] \amp= x - \dfrac{x^3}{3} + \dfrac{x^5}{5 \cdot 2!} - \dfrac{x^7}{7 \cdot 3!} + \cdots \pm \dfrac{x^{2n+1}}{(2n+1)\cdot n!}. \end{align*}
    Thus,
    \begin{equation*} \int_0^t e^{-x^2} \, dx\, \approx \left. x - \dfrac{x^3}{3} + \dfrac{x^5}{5 \cdot 2!} - \dfrac{x^7}{7 \cdot 3!} + \cdots\ \pm \dfrac{x^{2n+1}}{(2n+1) \cdot n!}\, \right|_0^t, \end{equation*}
    giving us, finally,

    Aside
    A formula for approximating the error function
    🔗
    an approximate formula for erf\((t)\text{:}\)
    \begin{equation*} \mbox{erf$(t)$} \approx \dfrac{2}{\sqrt{\pi}} \left(t - \dfrac{t^3}{3} + \dfrac{t^5}{5 \cdot 2!} - \dfrac{t^7}{\cdot 3!} + \cdots \pm \dfrac{t^{2n+1}}{(2n+1) \cdot n!} \right). \end{equation*}
    Thus if we needed to know, say, erf(1), we could quickly approximate it. For instance, letting \(n=6\text{,}\) we have
    \begin{align*} mbox{erf$(1)$} \amp\approx \dfrac{2}{\sqrt{\pi}} \left(1 - \dfrac{1}{3} + \dfrac{1}{5 \cdot 2!} - \dfrac{1}{7 \cdot 3!} + \dfrac{1}{9 \cdot 4!} - \dfrac{1}{11 \cdot 5!} + \dfrac{1}{13 \cdot 6!}\right)\\ [3pt] \amp\approx \dfrac{2}{\sqrt{\pi}} \left(1 - \dfrac{1}{3} + \dfrac{1}{10} - \dfrac{1}{42} + \dfrac{1}{216} - \dfrac{1}{1320} + \dfrac{1}{9360}\right)\\ [3pt] \amp\approx .746836\,\dfrac{2}{\sqrt{\pi}} \approx .842714, \end{align*}
    a value accurate to 4 decimals. If we had needed greater accuracy, we could simply have taken a larger value for \(n\text{.}\) For instance, if we take \(n=12\text{,}\) we get the estimate .8427007929…, where all 10 decimals are accurate (i.e., they don’t change as we take larger values \(n\)).

    🔗

    Evaluating Limits..

    Our final application of Taylor polynomials makes explicit use of the order of magnitude of the remainder. Consider the problem of evaluating a limit like
    \begin{equation*} \lim_{x \to 0} \dfrac{1 - \cos(x)}{x^2}. \end{equation*}
    Since both numerator and denominator approach \(0\) as \(x \to 0\text{,}\) it isn’t clear what the quotient is doing. If we replace \(\cos(x)\) by its third degree Taylor polynomial with remainder, though, we get
    \begin{equation*} \cos(x) = 1 - \dfrac{1}{2!} x^2 + R(x), \end{equation*}
    and \(R(x) = O(x^4)\) as \(x \to 0\text{.}\) Consequently, if \(x \neq 0\) but \(x \to 0\text{,}\) then
    \begin{align*} dfrac{1 - \cos(x)}{x^2} \amp= \dfrac{1-\left(1 - \tfrac{1}{2}x^2 + R(x)\right)}{x^2}\\ [3pt] \amp= \dfrac{\tfrac{1}{2}x^2 - R(x)}{x^2} = \dfrac{1}{2} - \dfrac{R(x)}{x^2}. \end{align*}
    Since \(R(x) = O(x^4)\text{,}\) we know that there is some constant \(C\) for which \(R(x)/x^4 \to C\) as \(x \to 0\text{.}\) Therefore,
    \begin{align*} lim_{x \to 0}\dfrac{1 - \cos(x)}{x^2} \amp= \dfrac{1}{2} - \lim_{x \to 0}\dfrac{R(x)}{x^2} = \dfrac{1}{2} - \lim_{x \to 0}\dfrac{x^2 \cdot R(x)}{x^4}\\ [3pt] \amp= \frac{1}{2} - \lim_{x \to 0} x^2 \cdot \lim_{x \to 0}\dfrac{R(x)}{x^4} = \frac{1}{2} - 0 \cdot C = \frac{1}{2}. \end{align*}
    🔗
    There is a way to shorten

    Aside
    Extending the ‘big oh’ notation
    🔗
    these calculations—and to make them more transparent—by extending the way we read the ‘big oh’ notation. Specifically, we will read \(O(q(x))\) as “some (unspecified) function that is the same order of magnitude as \(q(x)\)”.
    🔗
    Then, instead of writing \(\cos(x) = 1 - \tfrac{1}{2} x^2 + R(x)\text{,}\) and then noting \(R(x) = O(x^4)\) as \(x \to 0\text{,}\) we’ll just write
    \begin{equation*} \cos(x) = 1 - \tfrac{1}{2} x^2 + O(x^4) \qquad (x \to 0). \end{equation*}
    In this spirit,
    \begin{align*} dfrac{1 - \cos(x)}{x^2} \amp= \dfrac{1-\left(1-\tfrac{1}{2}x^2 + O(x^4)\right)}{x^2}\\ [3pt] \amp= \dfrac{\tfrac{1}{2}x^2 - O(x^4)}{x^2} = \tfrac{1}{2} +O(x^2) \qquad (x \to 0). \end{align*}
    We have used the fact that \(\pm O(x^4)/x^2 = O(x^2)\text{.}\) Finally, since \(O(x^2) \to 0\) as \(x \to 0\) (do you see why?), the limit of the last expression is just 1/2 as \(x \to 0\text{.}\) Thus, once again we arrive at the result
    \begin{equation*} \lim_{x \to 0} \dfrac{1 - \cos(x)}{x^2} = \dfrac{1}{2}. \end{equation*}
