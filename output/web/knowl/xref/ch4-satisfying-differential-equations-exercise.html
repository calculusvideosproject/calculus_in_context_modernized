(c)

Show that the function \(P(t) = A \cdot 2^{kt/.69}\) is a solution to the initial value problem
\begin{equation*} \dfrac{dP}{dt} = k\,P \qquad P(0) = A. \end{equation*}
Note that this describes a population that grows at the constant per capita rate \(k\) from an initial size of \(A\text{.}\)
