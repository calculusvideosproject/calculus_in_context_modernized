7.

This purpose of this exercise is to prove the fourth property listed in Theorem 3: \(\exp(rs) = (\exp(s))^r\text{,}\) for all real numbers \(r\) and \(s\text{.}\) The idea of the proof is the same as for Theorem 1: show that two different-looking functions solve the same initial value problem, thus demonstrating that the functions must be the same. The initial value problem is
\begin{equation*} y' = ry \qquad y(0) = 1. \end{equation*}
🔗

(a)

Show that \(P(t) = \exp(rt)\) solves the initial value problem. (You need to use the chain rule.)
🔗
🔗

(b)

Show that \(Q(t) = (\exp(t))^r\) solves the initial value problem. (Here use the chain \(Q = u^r\text{,}\) where \(u = \exp(t)\text{.}\) There is a bit of algebra involved.)
🔗
🔗

(c)

From parts (a) and (b), and the fact that an initial value problem has a unique solution, it follows that \(P(t) = Q(t)\text{,}\) for every \(t\text{.}\) Explain how this establishes the result.
