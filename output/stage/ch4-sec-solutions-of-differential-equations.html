    Section 4.2 Solutions of Differential Equations

    Subsection 4.2.1 Differential Equations are Equations

    Until now, we have viewed a system of differential equations

    Aside
    Differential equations give instructions for Euler’s method
    🔗
    as a set of instructions for “stepping into the future” (or the past). Put another way, an initial value problem was treated as a prescription for using Euler’s method to determine a set of functions which were then given either graphically or in tabular form.
    🔗
    In this section we take a new point of view: we will think of differential equations as equations for which we would like to find solutions in terms of functions which can be given by explicit formulas. While it is unfortunately the case that most differential equations do not have solutions which can be given by formulas, there are enough important classes of equations where such solutions do exist to make them worth studying. When such solutions can be found, we have a very powerful tool for examining the behavior of the phenomenon being modelled.
    🔗
    To see what this means, let’s look first at equations in algebra.

    Aside
    Equations have solutions
    🔗
    Consider the equation \(x^2 = x + 6\text{.}\) As it stands, this is neither true nor false. We make it true or false, though, when we substitute a particular number for \(x\text{.}\) For example, \(x = 3\) makes the equation true, because \(3^2 = 3 + 6\text{.}\) On the other hand, \(x = 1\) makes the equation false, because \(1^2 \neq 1 + 6\text{.}\) Any number that makes an equation true is called a solution to that equation. In fact, \(x^2 = x + 6\) has exactly two solutions: \(x = 3\) and \(x = -2\text{.}\)
    🔗
    We can view differential equations the same way. Consider, for example, the differential equation
    \begin{equation*} \dfrac{dy}{dt} = \dfrac{1}{2y}. \end{equation*}
    Because it involves the expression \(dy/dt\text{,}\) we understand that \(y\) is a function of \(t\text{.}\) As it stands, the differential equation is neither true nor false. We make it true or false, though, when we substitute a particular function for \(y\text{.}\) For example, \(y = \sqrt{t} = t^{1/2}\) makes the differential equation true. To see this, first look at the left-hand side of the

    Aside
    Substitute \(y = \sqrt{t}\) into the differential equation
    🔗
    equation:
    \begin{equation*} \dfrac{dy}{dt} = \tfrac{1}{2} t^{-1/2} = \dfrac{1}{2 \sqrt{t}}. \end{equation*}
    Now look at the right-hand side:
    \begin{equation*} \dfrac{1}{2y} = \dfrac{1}{2\sqrt{t}}. \end{equation*}
    The two sides of the equation are equal, so the substitution \(y = \sqrt{t}\) makes the equation true.
    🔗
    The function \(y = t^2\text{,}\) however, makes the differential equation false. The left-hand side is
    \begin{equation*} \dfrac{dy}{dt} = 2t, \end{equation*}
    but the right-hand side is
    \begin{equation*} \dfrac{1}{2y} = \dfrac{1}{2t^2}. \end{equation*}
    Since \(2t\) and \(1/2t^2\) are different functions, the two sides are unequal and the equation is therefore false.
    🔗
    We say that \(y = \sqrt{t}\) is a

    Aside
    A solution makes the equation true
    🔗
    solution to this differential equation. The function \(y = t^2\) is not a solution. To decide whether a particular function is a solution when the function is given by a formula, notice that we need to be able to differentiate the formula.
    🔗

    Aside
    If we view differential equations simply as instructions for carrying out Euler’s method, we need only the microscope equation \(\Delta y \approx y'\cdot \Delta t\) in order to find functions. However, if we want to find functions that are solutions to differential equations from our new point of view, we first need to introduce the idea of the derivative and the rules for differentiating functions.
    🔗
    Just as an algebraic equation can have more than one solution, so can a differential equation. In fact, we can show that \(y = \sqrt{t + C}\) is a solution to the differential equation
    \begin{equation*} \dfrac{dy}{dt} = \dfrac{1}{2y}, \end{equation*}
    for any value of the constant \(C\text{.}\) To evaluate the left-hand side \(dy/dt\text{,}\) we need the chain rule (Section 3.6). Let’s write
    \begin{equation*} y = \sqrt{u} \qquad \mbox{where} \qquad u = t + C. \end{equation*}
    Then the left-hand side is the function
    \begin{equation*} \dfrac{dy}{dt} = \dfrac{dy}{du} \cdot \dfrac{du}{dt} = \dfrac{1}{2\sqrt{u}} \cdot 1 = \dfrac{1}{2\sqrt{t + C}}. \end{equation*}
    Since the right-hand side of the differential equation is
    \begin{equation*} \dfrac{1}{2y} = \dfrac{1}{2 \sqrt{t + C}}, \end{equation*}
    the two sides are equal—no matter what value \(C\) happens to have.

    Aside
    A differential equation can have infinitely many solutions
    🔗
    This proves that every function of the form \(y = \sqrt{t + C}\) is a solution to the differential equation. Since there are infinitely many values that \(C\) can take, the differential equation has infinitely many different solutions!
    🔗
    If a differential equation arises in modelling a physical or biological process, the variables involved must also satisfy an initial condition. Suppose we add an initial condition to our differential equation:
    \begin{equation*} \dfrac{dy}{dt} = \dfrac{1}{2y} \qquad \mbox{and} \qquad y(0) = 5. \end{equation*}
    Does this problem have a solution—that is, can we find a function \(y(t)\) that is a solution to the differential equation and also satisfies the condition \(y(0) = 5\text{?}\)
    🔗
    Notice \(y = \sqrt{t}\) is not a solution to this new problem. Although it satisfies the differential equation, it fails to satisfy the initial condition:
    \begin{equation*} y(0) = \sqrt{0} = 0 \neq 5. \end{equation*}
    Perhaps one of the other solutions to the differential equation will work. When we evaluate the solution \(y = \sqrt{t + C}\) at \(t = 0\) we get
    \begin{equation*} y(0) = \sqrt{0 + C} = \sqrt{C}. \end{equation*}
    🔗
    We want this to equal 5, and it will if \(C = 25\text{.}\)

    Aside
    An initial value problem has only one solution
    🔗
    Thus, \(y = \sqrt{t + 25}\) is a solution to the initial value problem. Furthermore, the only value of \(C\) which will make \(y(0) = 5\) is \(C = 25\text{,}\) so the initial value problem has only one solution of the form \(\sqrt{t + C}\text{.}\) Here is the graph of this solution:
    🔗
    As always, you can use Euler’s method to find the function determined by an initial value problem, and you can graph that function using the program SIRPLOT, for example. How will that graph compare with this one? In the exercises you can explore this question.
    🔗

    Checking solutions versus finding solutions.

    Notice that we have only checked whether a given function solves an initial value problem; we have not constructed a formula to solve the problem. By this point you are probably wondering where the given solutions came from.
    🔗
    It is helpful to continue exploring the parallels with solutions of algebraic equations. In the case of the equation \(x^2 = x + 6\text{,}\) there are, of course, methods to find solutions. One possibility is to rewrite \(x^2 = x + 6\) in the form \(x^2 - x - 6 = 0\text{.}\) By factoring \(x^2 - x - 6\) as
    \begin{equation*} x^2 - x - 6 = (x - 3)(x + 2) \end{equation*}
    we can see that either \(x - 3 = 0\) (so \(x = 3\)), or \(x + 2 = 0\) (so \(x = -2\)). Another method is to use the quadratic formula
    \begin{equation*} x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{equation*}
    for the roots of the quadratic function \(ax^2 + bx + c\text{.}\) In our case, the quadratic formula yields
    \begin{equation*} x = \dfrac{-(-1) \pm \sqrt{1 - 4 \cdot 1 \cdot (-6)}} {2 \cdot 1} = \dfrac{1 \pm \sqrt{1 + 24\vphantom{(-6)}}}{2} = \dfrac{1 \pm 5}{2}, \end{equation*}
    so again we find that \(x\) must be either 3 or \(-2\text{.}\)
    🔗
    Thus we have at least two different methods

    Aside
    There are special methods to solve particular equations, but other methods work generally
    🔗
    for finding solutions to this particular equation. The methods we use to solve an algebraic equation depend very much on the equation we face. For example, there is no way to find a solution to \(\sin{x} = 2^x\) by factoring, or by using a “magic formula” like the quadratic formula. Nevertheless, there are methods that do work. In Chapter 1 and Chapter 2 we dealt with similar problems by using a computer graphing utility that could zoom in on the point of intersection of two graphs. In Chapter 6 we will introduce another tool, the Newton–Raphson method, for finding roots. These are both powerful methods, because they will work with nearly all algebraic equations. It is important to recognize that these numerical methods really do solve the problem, even though they do not give solutions in closed form the way the quadratic formula does.
    🔗
    The situation is entirely analogous in dealing with differential equations. The methods we use to solve a differential equation depend on the equation we face. A course in differential equations provides methods for finding formulas that solve many different kinds of differential equations. The methods are like the quadratic formula in algebra, though—they give a complete solution, but they work only with differential equations that have a very specific form. This course will not attempt to survey the methods that find such formulas, although in the next sections we will see effective methods for dealing with some special subcases.
    🔗
    It is important to realize, though, that Euler’s method is always there if we can’t think of anything cleverer, and it really does provide solutions.

    Aside
    Most initial value problem have one, and only one, solution. Euler’s method will find it.
    🔗
    In fact, most initial value problems have one, and only one, solution, and Euler’s method can be used to determine this unique solution. If we can also find a formula for the solution, then it must be the same solution as that produced by Euler’s method. In more advanced courses you will see a proof that this is true in general, provided some mild conditions are satisfied. To emphasize the importance of this idea, we give it a name:
    🔗
    Existence and Uniqueness Principle Under most conditions, an initial value problemhas one and only one solution.
    🔗
    The existence and uniqueness principle is one of the most important mathematical results in the theory of differential equations.
    🔗
    We will continue to rely primarily on Euler’s method, which generates solutions for nearly all differential equations.
    🔗
    However, there are clear benefits to having a formula for the solution to a differential equation, allowing us to investigate questions that we can’t answer very well if we only have solutions given by Euler’s method. In this section, we will look at some of those benefits.

    Subsection 4.2.2 World Population Growth

    Two models.

    In the exercises in the last section, we looked at two different models that seek to describe how the world population will grow. One model assumed constant per capita growth—rate of change proportional to population size. The other assumed “supergrowth"—rate of change proportional to a higher power of the population size. Let’s write \(P\) for the population size in the constant per capita growth model and \(Q\) for the population size in the supergrowth model. In both cases, the population is expressed in billions of persons and time is measured in years, with \(t=0\) in 1990. In this notation,

    Aside
    Models for world population growth
    🔗
    the two models are
    \begin{equation*} \begin{array}{rll} \mbox{constant per capita:} & \dfrac{dP}{dt} =0.02\,P & P(0) = 5; \\[12pt] \mbox{supergrowth:} & \dfrac{dQ}{dt} =0.015\,Q^{1.2} & Q(0) = 5. \end{array} \end{equation*}
    🔗
    By using Euler’s method, we discover that the two models predict fairly similar results over sixty years, although the supergrowth model lives up to its name by predicting larger populations than the constant per capita growth model as time passes:
    \begin{equation*} \begin{array}{rcc} t & P & Q \\ \hline -10 & 4.09 & 4.08 \\ 0 & 5.00 & 5.00 \\ 10 & 6.11 & 6.18 \\ 50 & 13.59 & 15.94 \end{array} \end{equation*}
    These estimates are accurate to one decimal place, and that level of accuracy was obtained with the step size \(\Delta t=0.1\text{.}\)
    🔗
    However, the predictions made by the models differ widely over longer time spans. If we use Euler’s method to estimate the populations after 240 years, we get

    First of all,

    Aside
    Checking the initial condition
    🔗

    🔗

    Aside
    Left-hand side
    🔗
    To differentiate \(Q(t)\text{,}\) we will write \(Q\) as a chain of functions:

    🔗

    A formula for constant per capita growth.

    The constant per capita growth model for the world population that we are considering is
    \begin{equation*} \dfrac{dP}{dt} = 0.02\, P \qquad P(0) = 5. \end{equation*}
    This differential equation has a very simple form; if \(P(t)\) is a solution, then the derivative of \(P\) is just a multiple of \(P\text{.}\) We have already seen in Chapter 3 that exponential functions behave this way (Exercise Group 4.3.5.5–7). For example, if \(P(t) = 2^t\text{,}\) then
    \begin{equation*} \dfrac{dP}{dt} = 0.69 \cdot 2^t = 0.69 \, P. \end{equation*}
    Of course, the multiplier that appears here is 0.69, not 0.02, so \(P(t) = 2^t\) is not a solution to our problem.
    🔗
    However, the multiplier that appears

    Aside
    Exponential functions satisfy \(dy/dt = ky\)
    🔗
    when we differentiate an exponential function changes when we change the base. That is, if \(P(t) = b^t\text{,}\) then \(P'(t) = k_b \cdot b^t\text{,}\) where \(k_b\) depends on \(b\text{.}\) Here is a sample of values of \(k_b\) for different bases \(b\text{:}\)
    \begin{equation*} \begin{array}{rc} b & k_b \\ \hline 0.5 & -0.693147\ldots \\ 2 & \phantom{-}0.693147\ldots \\ 3 & \phantom{-}1.098612\ldots \\ 10 & \phantom{-}2.302585\ldots \end{array} \end{equation*}
    Notice that \(k_b\) gets larger as \(b\) does. Since 0.02 lies between \(-0.693147\) and \(+.693147\text{,}\) the table suggests that the value of \(b\) we want lies somewhere between 0.5 and 2.
    🔗
    We can say even more about the multiplier. Since \(P'(t) = k_b \cdot P(t)\) and \(P(t) = b^t\text{,}\) we find
    \begin{equation*} P'(0) = k_b \cdot P(0) = k_b \cdot b^0 = k_b \cdot 1 = k_b. \end{equation*}
    In other words, \(k_b\) is the slope of the graph of \(P(t) = b^t\) at the origin.
    🔗
    Thus, we will be able to solve the differential equation \(dP/dt = 0.02\,P\) if we can find an exponential function \(P(t) = b^t\)

    The correct exponential function has slope 0.02 at the origin
    🔗
    whose graph has slope 0.02 at the origin. This is a problem that we can solve with a computer microscope.     \begin{equation*} P(t) = (1.0202)^t. \end{equation*}

    \begin{equation*} P(0) = (1.0202)^0 = 1 \neq 5. \end{equation*}
    This is easy to fix; \(P(t) = 5 \cdot (1.0202)^t\) satisfies both conditions. More generally, \(P(t) = C \,(1.0202)^t\) satisfies the initial condition \(P(0) = C\) as well as the differential equation \(P'(t) = 0.02 \,P(t)\text{.}\) To check the initial condition, we compute
    \begin{equation*} P(0) = C \, (1.0202)^0 =C \cdot 1 = C. \end{equation*}

    \begin{equation*} P'(t)= (C \, (1.0202)^t)' = C \cdot ((1.0202)^t)'= C \cdot (.02 \, (1.0202)^t) = 0.02 \, P(t). \end{equation*}
    So we have verified that the solution to our problem is

    \begin{equation*} P(t) = 5 \, (1.0202)^t. \end{equation*}

    Subsection 4.2.3 Differential Equations Involving Parameters

    🔗
    The \(S\)-\(I\)-\(R\) model contained two parameters—the transmission

    Aside
    How do parameters affect solutions?
    🔗
    and recovery coefficients \(a\) and \(b\text{.}\) When we used Euler’s method to analyze \(S\text{,}\) \(I\text{,}\) and \(R\text{,}\) we were working numerically. To do the computations, we had to give the parameters definite numerical values. That made it more difficult to deal with our questions about the effects of changing the parameters. As a result, we took other approaches to explore those questions. For example, we used algebra to see that there was a threshold for the spread of the disease: if there were fewer than \(b/a\) people in the susceptible population, the infection would fade away.
    🔗
    This is the situation generally. Euler’s method can be used to produce solutions to a very broad range of initial value problems. However, if the model includes parameters, then we usually want to know how the solutions are affected when the parameters change. Euler’s method is a rather clumsy tool for investigating this question. Other methods—ones that don’t require the values of the parameters to be fixed—work better. One possibility is to start with a formula.
    🔗
    The supergrowth problem illustrates

    Aside
    Supergrowth parameters
    🔗
    both how questions about parameters can arise and how useful a formula for the solution can be to answer the questions. One of the most striking features of the supergrowth model is that it predicts the population becomes infinite in 241.6…years. That prediction was based on an initial population of 5 billion and a growth constant of 0.015. Suppose those values turn out to be incorrect, and we need to start with different values. Will that change the prediction? If so, how?
    🔗
    We should treat the initial population and the growth constant as parameters—that is, as quantities that can vary, although they will have fixed values in any specific situation that we consider. Suppose we let \(A\) denote the size of the initial population, and \(k\) the growth constant. If we incorporate these parameters into the supergrowth model, the initial value problem takes this form:
    \begin{equation*} \dfrac{dQ}{dt} = k\, Q^{1.2} \qquad Q(0) = A \end{equation*}
    🔗
    Here is the formula for a function that solves this

    Aside
    The supergrowth solution with parameters
    🔗
    problem:
    \begin{equation*} Q(t) =\left( \frac{1}{\sqrt[5]{A}} -0.2kt \right)^{-5} \end{equation*}
    Notice that, when \(A = 5\) and \(k = 0.015\text{,}\) this formula reduces to the one we considered earlier.
    🔗
    Let’s check

    Aside
    Checking the formula
    🔗
    that the formula does indeed solve the initial value problem. First, the initial condition:
    \begin{equation*} Q(0)=\left( \frac{1}{\sqrt[5]{A}} -0.2k \cdot 0 \right)^{-5} = \left(\frac{1}{\sqrt[5]{A}}\right)^{-5} = (\sqrt[5]{A})^5 = A. \end{equation*}
    Next, the differential equation. To differentiate \(Q(t)\) we introduce the chain
    \begin{equation*} Q = u^{-5} \qquad \mbox{where} \qquad u = \frac{1}{\sqrt[5]{A}} -0.2kt. \end{equation*}
    We see that \(dQ/du = -5\,u^{-6}\text{.}\) Since \(u\) is a linear function of \(t\) in which the multiplier is \(-0.2k\text{,}\) we also have \(du/dt = -0.2k\text{.}\) Thus, by the chain rule,
    \begin{equation*} \dfrac{dQ}{dt} = \dfrac{dQ}{du} \cdot \dfrac{du}{dt} = -5\,u^{-6} \cdot (-0.2k) = k\,u^{-6}. \end{equation*}
    That is the left-hand side of the differential equation. To evaluate the right-hand side, we use the fact that \(Q = u^{-5}\text{.}\) Thus
    \begin{equation*} k\,Q^{1.2} = k\,Q^{6/5} = k(u^{-5})^{6/5} = k\,u^{-5 \cdot 6/5} = k\,u^{-6}. \end{equation*}
    Since both sides equal \(k\,u^{-6}\text{,}\) they equal each other, proving that \(Q(t)\) is a solution to the differential equation.
    🔗
    Next, we ask when the population becomes infinite. Exactly as before, this will happen when the denominator of the formula for \(Q(t)\) becomes

    Aside
    The time to infinity
    🔗
    zero:
    \begin{equation*} \dfrac{1}{\sqrt[5]{A}} - 0.2\,kt = 0, \qquad \mbox{or} \qquad t = \dfrac{1}{0.2\,k\sqrt[5]{A}}. \end{equation*}
    Here, in fact, is a formula that tells us how each of the parameters \(A\) and \(k\) affects the time it takes for the population to become infinite.
    🔗
    Let’s use \(\tau\) (the Greek letter “tau”) to denote the “time to infinity.” For example, if we double the initial population, so \(A = 10\) billion people, while keeping the original growth constant \(k = 0.015\text{,}\) then the time to infinity is
    \begin{equation*} \tau = \dfrac{1}{0.003 \times \sqrt[5]{10}} \approx 210.3 \ \mbox{years}. \end{equation*}
    By contrast, if we double the growth rate, to \(k = 0.030\text{,}\) while keeping the original \(A = 5\text{,}\) then the time to infinity is only
    \begin{equation*} \tau = \dfrac{1}{0.006 \times \sqrt[5]{5}} \approx 120.8 \ \mbox{years} \end{equation*}
    Conclusion: doubling the growth rate has a much greater impact than doubling the initial population.
    🔗
    For any specific growth rate and initial population,

    Aside
    Uncertainty in the size of \(\tau\)
    🔗
    we can always calculate the time to infinity. But we can actually do more; the formula for \(\tau\) allows us to do an error analysis along the patterns described in Section 3.4. For example, suppose we are uncertain of our value of the growth rate \(k\text{;}\) there may be an error of size \(\Delta k\text{.}\) How uncertain does that make us about the calculated value of \(\tau\text{?}\) Likewise, if the current world population \(A\) is known only with an error of \(\Delta A\text{,}\) how uncertain does that make \(\tau\text{?}\) Also, how are the relative errors related? Let’s do this analysis, assuming that \(k = 0.015\) and \(A = 5\text{.}\)
    🔗
    Our tool is the error propagation equation—which is

    Aside
    How an error in \(k\) propagates
    🔗
    the microscope equation. If we deal with \(k\) first, then
    \begin{equation*} \Delta \tau \approx \dfrac{\partial \tau}{\partial k} \cdot \Delta k. \end{equation*}
    We have used partial derivatives because \(\tau\) is a function of two variables, \(A\) as well as \(k\text{.}\) If we write
    \begin{equation*} \tau = \dfrac{1}{0.2\sqrt[5]{A}} \, k^{-1}, \end{equation*}
    then the differentiation rules yield
    \begin{equation*} \dfrac{\partial \tau}{\partial k} = -1 \cdot \dfrac{1}{0.2\sqrt[5]{A}} \, k^{-2} = \dfrac{-1}{0.2\sqrt[5]{5}} \times (0.015)^{-2} \approx -16106. \end{equation*}
    Thus \(\Delta \tau \approx -16106 \cdot \Delta k\text{.}\) For example, if the uncertainty in the value of \(k = 0.015\) is \(\Delta k = \pm 0.001\text{,}\) then the uncertainty in \(\tau\) is about \(\mp 16\) years.
    🔗
    To determine how an error in \(A\) propagates to \(\tau\text{,}\)

    Aside
    How an error in \(A\) propagates
    🔗
    we first write
    \begin{equation*} \tau = \dfrac{1}{0.2\,k} A^{-1/5}. \end{equation*}
    Then
    \begin{equation*} \dfrac{\partial \tau}{\partial A} = -\dfrac{1}{5} \cdot \dfrac{1}{0.2\,k} A^{-6/5} = \dfrac{-1}{5 \times.2 \times 0.015} \times 5^{-6/5} \approx -9.7. \end{equation*}
    The error propagation equation is thus \(\Delta \tau \approx -9.7 \cdot \Delta A\text{.}\) If the uncertainty in the world population is about 100 million persons, so \(\Delta A = \pm 0.1\text{,}\) then the uncertainty in \(\tau\) is less than 1 year.
    🔗
    To complete the analysis,

    Aside
    Relative errors
    🔗
    let’s compare relative errors. This involves a lot of algebra. To see how an error in \(k\) propagates, we have
    \begin{equation*} \Delta \tau \approx -\dfrac{\Delta k}{0.2\,k^2\sqrt[5]{A}} \qquad \mbox{and} \qquad \tau = \dfrac{1}{0.2\,k\sqrt[5]{A}}. \end{equation*}
    We can therefore compute that a given relative error in \(k\) propagates as
    \begin{equation*} \dfrac{\Delta \tau}{\tau} \approx -\dfrac{\Delta k}{0.2\,k^2\sqrt[5]{A}} \cdot \dfrac{0.2\,k\sqrt[5]{A}}{1} = -\dfrac{\Delta k}{k}. \end{equation*}
    Thus, a 1% error in \(k\) leads to a 1% error in \(\tau\text{,}\) although the sign is reversed.
    🔗
    To analyze how a given relative error in \(A\) propagates, we start with
    \begin{equation*} \Delta \tau \approx -\dfrac{1}{5} \cdot \dfrac{\Delta A}{0.2\,k A^{6/5}}. \end{equation*}
    Then
    \begin{equation*} \dfrac{\Delta \tau}{\tau} \approx -\dfrac{1}{5} \cdot \dfrac{\Delta A}{0.2\,k A^{6/5}} \cdot \dfrac{0.2\,k\sqrt[5]{A}}{1} = -\dfrac{1}{5} \cdot \dfrac{\Delta A}{A}. \end{equation*}
    This says that it takes a 5% error in \(A\)

    Aside
    How sensitive \(\tau\) is to errors in \(k\) and \(A\)
    🔗
    to produce a 1% error in \(\tau\text{.}\) Consequently, the time to infinity \(\tau\) is 5 times more sensitive to errors in \(k\) than to errors in \(A\).

    🔗

The tool of widest applicability is Euler’s method.     Motion.

    Newton created the calculus to study the motion of the planets. He said that all motion obeys certain basic laws. One law says that the velocity of an object changes only if a force acts on the body. Furthermore, the rate at which the velocity changes is proportional to the force. By knowing the forces that act on a body we can construct—and then solve—a differential equation for the velocity.
    🔗
    Falling bodies—with gravity. A body falling through the air starts up slowly but picks up speed as it falls. Its velocity is thus changing, so there must be a force acting. We call the force that pulls objects to the earth gravity. At the surface of the earth, the rate of change of velocity caused by gravity is essentially the same for all objects.
    🔗
    Suppose an object is \(x\) meters above the surface of the earth after \(t\) seconds have passed. Then, by definition, its velocity is
    \begin{equation*} v = \dfrac{dx}{dt} \ \mbox{meters/second}. \end{equation*}
    According to Newton’s laws of motion, the force of gravity causes the velocity to change, and we can write
    \begin{equation*} \dfrac{dv}{dt} = -g. \end{equation*}
    Here \(g\) is a constant whose numerical value is about 9.8 meters/second per second. Since \(x\) and \(v\) are positive when measured upwards, but gravity acts downwards, a minus sign is needed in the equation for \(dv/dt\text{.}\) (The derivative of velocity is commonly called acceleration, and \(g\) is called the acceleration due to gravity.)
    🔗

    The oscillating spring.

    Springs can smooth out life’s little irregularities (as in the suspension of a car) or amplify and measure them (as in earthquake detection devices). Suppose a spring that hangs from a hook has a weight at its end. Let the weight come to rest. Then, when the weight moves, let \(x\) denote the position of the weight above the rest position. (If \(x\) is negative, this means the weight is below the rest position.) If you pull down on the weight, the spring pulls it back up. If you push up on the weight, the spring (and gravity) push it back down. This push is the spring force.
    🔗
    The simplest assumption is that the spring force is proportional to the amount \(x\) that the spring has been stretched: force = \(-c^2x\text{.}\) The constant \(c^2\) is customarily written as a square to emphasize that it is positive. The minus sign tells us the force pushes down if \(x > 0\) (so the weight is above the rest position), but it pushes up if \(x < 0\text{.}\)
    🔗
    If \(v = dx/dt\) is the velocity of the weight, then Newton’s law of motion says
    \begin{equation*} \dfrac{dv}{dt} = - c^2 x. \end{equation*}
    Suppose we move the weight to the point \(x = a\) on the scale, hold it motionless momentarily, and then release it at time \(t = 0\text{.}\) This determines the initial value problem
    \begin{equation*} \begin{array}{ll} x' = v & x(0) = a \\ v' = -c^2 x \qquad & v(0) = 0. \end{array} \end{equation*}
