# Calculus in Context Modernized
A “modernized" version of the original Calculus in Context book by the Five Colleges Calculus Project.

This version of the textbook incorporates Sage cells, Geogebra applets, and other interactive elements; incorporates materials and ideas from the Calculus Videos Project; adds new depth and perspective on some foundational ideas (like constant rate of change); and incorporates additional problems and exercises.
